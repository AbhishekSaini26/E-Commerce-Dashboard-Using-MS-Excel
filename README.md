# E-Commerce Sales & Customer Analytics (Excel Dashboard)

## 📌 Project Overview
An interactive Microsoft Excel dashboard analyzing order fulfillment, payment channels, regional product demand, and overall net revenue for an e-commerce platform.

## 📊 Key Business Metrics & Insights
- **Net Revenue:** Tracked **₹1.14 Cr+** in net sales.
- **Total Orders:** Processed **4,800+** orders across multiple product categories.
- **Average Order Value (AOV):** **₹2,393.27** per transaction.
- **Return Rate:** Flagged a **14%** return rate to help optimize product quality control. **Regional Dominance:** Identified West and East regions as primary revenue generator.

## 🛠️ Tools & Technologies Used
- **Data Analysis:** Microsoft Excel (Pivot Tables, Pivot Charts, Advanced Formulas, Slicers)
- **Key Formulas:** `XLOOKUP`, `SUMIFS`, `COUNTIFS`, `AVERAGEIFS`

## 💡 Key Features
1. **Interactive Slicers:** Filter dataset dynamically by City (Agra, Chandigarh, Gurugram, Jaipur, etc.), Category, and Payment Method (COD, UPI, Net Banking, Credit/Debit Card)[cite: 5].
2. **Monthly Sales Trendline:** Track seasonal revenue spikes across 12 calendar months[cite: 5].
3. **Fulfillment Tracking:** Donut chart breakdown of Order Status (Delivered, Pending, Cancelled, Returned)
